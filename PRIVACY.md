# Privacy Policy for Un-definer

Un-definer does not collect, store, sell, share, or transmit user data.

The extension runs locally in the user's browser on Codeforces pages. It reads the currently displayed source code only to rewrite macros and simple typedefs visually on the page.

Un-definer does not use analytics, tracking, remote code, external servers, or third-party services.

Un-definer is an independent tool and is not affiliated with, endorsed by, or sponsored by Codeforces.
